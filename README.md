## LINQ-запросы

### Задание
Разработать консольное приложение с дружественным интерфейсом для работы с базой данных «Детские товары» из Excel-файла. 
Приложение должно выполнять: чтение, просмотр, удаление, добавление, 4 LINQ-запроса и сохранение изменений обратно в файл.

### Алгоритм решения
Программа разделена на логические части:
1. **Классы-модели** (`Shop`, `Category`, `Product`, `Movement`) описывают структуру таблиц базы данных. В них есть свойства с проверками (валидацией), конструкторы и переопределенный метод `ToString()`.
2. **Класс `DbHelper`** — вспомогательный класс, который хранит списки `List<T>` и выполняет всю основную работу:
   * `Load()` — читает Excel-файл с помощью библиотеки `ClosedXML` и превращает строки в объекты.
   * `Save()` — записывает текущее состояние списков обратно в новый Excel-файл.
   * `AddElement()` / `DeleteByKey()` — позволяют добавлять и удалять записи, используя LINQ-метод `FirstOrDefault`.
   * `Query1` - `Query4` — четыре LINQ-запроса для выборки и анализа данных.
3. **Класс `Program`** — реализует меню `switch-case` и обрабатывает возможные ошибки (например, если файл не найден или введена неверная цена).

### Описание LINQ-запросов
В программе реализованы 4 запроса согласно заданию:
1. **Запрос 1 (1 таблица, перечень):** Выводит список всех товаров с ценой продажи > 500 руб.
2. **Запрос 2 (2 таблицы, одно значение):** Считает общую выручку от продаж, объединяя таблицы «Движение» и «Товар».
3. **Запрос 3 (3 таблицы, перечень):** Выводит товары, которые продавались в Худонковом районе. Использует `join` для таблиц «Движение», «Магазин» и «Товар».
4. **Запрос 4 (3+ таблицы, одно значение):** Считает общую стоимость детских товаров из категории «Игрушки на радиоуправлении 12+», проданных магазинами Худонкового района за 1-5 августа 2024 года. Использует 4 таблицы.
